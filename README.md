# FoF Categories

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/fof/categories.svg)](https://packagist.org/packages/fof/categories)

A [Flarum](http://flarum.org) extension. Traditional category layout for Flarum.

![On Desktop](https://i.imgur.com/oAOusDE.png)

![On Mobile](https://i.imgur.com/HA1DwwC.png)

### Installation

Install with composer:

```sh
composer require fof/categories
```

### Updating

```sh
composer update fof/categories
```
